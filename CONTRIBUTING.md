This file is a guid to anyone who wants to contribute to this project. The project incorporates a 7 part \(so far\) structure to help in new ROS2 users/learners to make and operate their first robot like many others including myself.

# What is the Goal?

This repository is a comprehensive guide to building a waypoint follower with ROS 2 and Nav2. It is structured as a series of projects, with each project representing a major step in the navigation stack setup.

Our current goal \(momentarily\) is to complete the documentation for each project. Your contribution will make this repository a valuable resource for other beginners learning ROS 2 and Nav2. It will also help new Git users to understand the basics of interaction with version control and this online portal.

The main task is to create a detailed README.md file for each of the 7 projects in the repository. A template README.md is provided in the first project to serve as a guide.

## Prerequisites

1. ROS2 Jazzy
2. SLAM Toolbox
3. Rviz2
4. Nav2 Stack
5. Gazebo Sim \(Harmonic\)

Each of the respective installations can be found online.
